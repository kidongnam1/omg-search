Installation Guide

Obsidian vault를 Gemini 기반 지식 작업실로 만드는 플러그인 설치 및 설정 가이드

Install Setup Config Diagnose Mobile Troubleshoot
Step 1

Install the Plugin

두 가지 설치 방법 중 하나를 선택하세요.

1

릴리즈 파일 다운로드

최신 릴리즈에서 main.js, manifest.json, styles.css 세 파일을 다운로드합니다.

2

플러그인 폴더 생성

볼트 안에 플러그인 폴더를 만듭니다.

Terminal
.obsidian/plugins/master-of-knowledge/
3

파일 복사 및 활성화

다운로드한 세 파일을 해당 폴더에 넣고, Obsidian 설정 > Community Plugins에서 Master of Knowledge를 활성화합니다.

ℹ
Plugin ID 변경 안내 v2.0.0부터 플러그인 ID가 master-of-knowledge로 변경되었습니다. 이전 BRAT 빌드(obsidian-gemini-sync)에서 업그레이드하는 경우 새 폴더명으로 설치하고 설정을 복사하세요.
1

저장소 클론

볼트의 플러그인 디렉토리에 저장소를 클론합니다.

Terminal
cd your-vault/.obsidian/plugins/
git clone https://github.com/kidongnam1/omg-search.git master-of-knowledge
2

의존성 설치 및 빌드

Terminal
cd master-of-knowledge
npm install
npm run build
3

플러그인 활성화

Obsidian을 재시작하거나 Community Plugins를 새로고침한 후 Master of Knowledge를 활성화합니다.

ℹ
개발 모드 npm run dev로 watch 모드를 실행하면 코드 변경 시 자동으로 다시 빌드됩니다.
Step 2

Initial Setup

플러그인을 활성화한 후 아래 순서대로 설정합니다.

1

Gemini API 키 발급

Google AI Studio에서 새 API 키를 만듭니다. 키는 보통 AIza로 시작합니다.

2

API 키 입력 및 검증

Obsidian 설정 > Master of Knowledge로 이동하여 API 키를 붙여 넣고 Verify 버튼을 누릅니다.

3

File Search 진단 (권장)

노트 동기화를 사용할 예정이라면 Diagnose File Search를 눌러 업로드/import 권한을 확인합니다.

4

동기화 폴더 선택

Gemini에 동기화할 폴더를 하나 이상 선택합니다 (예: Notes, Knowledge).

5

초기 동기화 실행

Sync Now를 눌러 선택한 폴더의 마크다운 파일을 Gemini File Search에 동기화합니다.

6

대화 시작

왼쪽 리본의 채팅 아이콘을 클릭하거나 Ctrl/Cmd + P > "Open Master of Knowledge"로 대시보드를 열고 노트에 대해 질문합니다.

⚠
API 키 보안 API 키는 플러그인의 data.json 파일에 로컬 저장됩니다. 이 파일을 절대 공유하지 마세요.

Diagnostics

File Search Diagnostics

Verify는 통과하지만 Sync가 실패하는 경우, Diagnose File Search로 단계별 원인을 파악합니다.

models

Gemini 모델 호출 자체가 실패. API 키가 유효하지 않음.

file_search_store

File Search store 생성/조회 실패. 키 권한 문제 가능성.

files_upload

Files API 업로드 실패. 키 제한 또는 호환성 문제.

import_file

업로드는 됐지만 File Search store로 import 실패.

⚠
AQ... 키 호환성 문제 새 Google AI Studio 키가 AQ...로 시작하고 files_upload 또는 import_file 단계에서 403이 발생하면, Gemini File Search와 새 Auth key 호환 문제일 수 있습니다. 기존 AIza... 키 또는 새 Google Cloud 프로젝트/키를 사용해보세요.

Help

Troubleshooting

자주 발생하는 문제와 해결 방법입니다.

  • Google AI Studio에서 새 키를 발급하세요 (보통 AIza로 시작).
  • Google Cloud 프로젝트에서 Generative Language API가 활성화되어 있는지 확인하세요.
  • API 키의 Application restrictions = None으로 설정 (HTTP referrer/IP 제한이 File Search를 차단할 수 있음).
  • 키/프로젝트를 바꿨다면 Reset store 후 Sync Now 실행.
  • Verify는 /models와 /fileSearchStores를 함께 검사합니다.
  • Sync는 uploadToFileSearchStore 우선, 실패 시 Files API + importFile 폴백 사용.
  • 계속 실패하면 Diagnose File Search로 단계별 확인.
  • Sync 폴더가 올바르게 선택되었는지 확인합니다.
  • Diagnose File Search를 실행해 실패 단계를 확인합니다.
  • API 키가 AQ...이고 401/403이 발생하면 File Search 호환/제한 문제일 수 있습니다.
  • Sync Dashboard에서 synced 파일 수를 확인하세요.
  • 선택한 sync 폴더 안의 노트만 Gemini File Search 대상입니다.
  • 답변 아래 Sources가 표시되는지 확인하세요.
  • Agent Timeout 값을 늘려보세요.
  • Antigravity/AGY CLI 경로를 설정에서 Auto-detect하거나 직접 지정하세요.
  • Agent는 Gemini API 예산에 포함되지 않습니다 (별도 키 사용).
  • API 키가 유효한지 다시 확인하세요.
  • 인터넷 연결을 확인하세요.
  • 개발자 콘솔(Ctrl+Shift+I)에서 오류를 확인하세요.
